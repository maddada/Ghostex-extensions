# Lazygit

Open [Lazygit](https://github.com/jesseduffield/lazygit) for the active Ghostex
project. The terminal starts in the project's path, including the selected
worktree, so Lazygit opens the repository you are currently working in.

## Requirements

Install `lazygit` and make sure it is available on your `PATH`. Ghostex checks
for the executable before opening the terminal and reports when it is missing.

Choose in the extension settings whether Lazygit opens in a split to the right
of the current terminal or in a new terminal tab.

## Permissions

- `exec`: runs the `lazygit` command in a terminal pane.
