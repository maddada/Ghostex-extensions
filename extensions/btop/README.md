# System Monitor

Open [btop](https://github.com/aristocratos/btop) in a Ghostex terminal to
inspect CPU, memory, disk, network, and process activity without leaving your
workspace.

## Requirements

Install `btop` and make sure it is available on your `PATH`. Ghostex checks for
the executable before opening the terminal and reports when it is missing.

Choose in the extension settings whether System Monitor opens in a split to the
right of the current terminal or in a new terminal tab.

## Permissions

- `exec`: runs the `btop` command in a terminal pane.
