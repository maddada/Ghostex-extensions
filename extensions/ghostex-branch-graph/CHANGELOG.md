# Changelog

## [0.6.0] - {PR_MERGE_DATE}

- Initial catalog release of Branch Graph: colored commit lanes, merges, refs,
  search, commit details, pagination, and automatic project/worktree tracking.
- Add upstream status, fetch timestamps, optional background fetch, and explicit
  Fetch, fast-forward Pull, and single-branch Push actions.
- Support dark/light themes, a compact layout, and a resizable details pane.
- Include complete source, reproducible bundles, local-remote integration tests,
  UI checks, and screenshots with fictional repository data.
- Keep the optional native glass/titlebar adapter outside the catalog package;
  the graph works independently on the stock renderer.

Earlier development releases are documented in the
[source project's changelog](https://github.com/knutpfr/ghostex-branch-graph/blob/main/CHANGELOG.md).
